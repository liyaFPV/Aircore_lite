# Aircore_lite

**Aircore_lite** — ответвление от оригинального **Aircore**, созданное как более доступная версия оригинального проекта со своими нюансами и дополнительными фишками.

## Детали

| Компонент  | Статус |
|------------|--------|
| Экран      | ✅ Работает |
| DS1302 RTC | ✅ Работает |
| Button     | ✅ Работает |
| BME280     | 🔄 Эмуляция |
| DS18B20    | 🔄 Эмуляция |

## Функции

| Имя | Описание | Статус |
|:---:|:---|:---:|
| Главный экран | Отображает время, дату и другие основные данные | 🔧 В работе |
| Графики за день | Отображают данные в виде графика за день. Показываются название данных, сам график, минимальное и максимальное значение | ✅ Работае |
| Графики за час | То же самое, что и графики за день, но данные отображаются за час | ✅ Работае |
